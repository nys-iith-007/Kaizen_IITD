# Kaizen — NSS IIT Delhi Annual Fest Website

Responsive frontend project for the NSS IIT Delhi Annual Fest **Kaizen**.

## Features
- Responsive Bootstrap navigation
- Interactive landing page
- Event cards and programme sections
- Responsive event schedule
- Registration form with client-side interaction
- Custom CSS styling
- Mobile-friendly layout

## Tech Stack
HTML5, CSS3, Bootstrap 5, JavaScript

## Structure
```text
Kaizen_IIT_Delhi/
├── index.html
├── css/style.css
├── js/script.js
└── README.md
```

## Run
Open `index.html` directly in a browser, or run `python -m http.server 8000` from the project directory and visit `http://localhost:8000`.
